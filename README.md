# 🐆 Sistemas de Alarmas Jaguar

Sitio web oficial de comercialización y landing page para **Sistemas de Alarmas Jaguar**, especializados en soluciones de seguridad, protección y alarmas de alta precisión para motocicletas.

🌐 **Sitio Web desplegado:** [https://jorgeazapata.github.io/jaguarsecurity/](https://jorgeazapata.github.io/jaguarsecurity/)

---

## 📌 Descripción del Proyecto

Este proyecto es una plataforma web orientada al usuario final y clientes mayoristas/minoristas interesados en proteger sus motocicletas. Presenta la gama de alarmas, características técnicas de los equipos, métodos de instalación y canales de contacto directo para compras e información.

---

## 🚀 Características Principales

- **Catálogo de Productos:** Exposición visual y detallada de los sistemas de alarma para motos (funciones de encendido remoto, sensor de golpe, corte de encendido / anti-atraco, sirena).
- **Diseño Responsivo:** Optimizado para una navegación fluida desde dispositivos móviles (smartphones) y ordenadores.
- **Canal Directo de Contacto:** Botón de interacción directa a WhatsApp y redes sociales para consultas inmediatas y pedidos.
- **Carga Rápida y Ligera:** Desarrollado sin sobrecarga de dependencias para garantizar una experiencia ágil al usuario.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio web.
- **CSS3:** Estilos personalizados, diseño adaptativo (responsive design) y animaciones.
- **JavaScript (ES6+):** Lógica de interacción en el sitio, menús y comportamiento de la interfaz.
- **GitHub Pages:** Alojamiento y despliegue del sitio en la web.

## 💻 Desarrollo Local

Si deseas clonar el proyecto para realizar ajustes locales o contribuciones:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/jorgeazapata/jaguarsecurity.git
   ```
2. **Navegar al directorio:**
   ```bash
   cd jaguarsecurity
   ```
3. **Abrir el archivo principal:**
   Abre el archivo `index.html` en tu navegador de preferencia o utilízalo con una extensión como *Live Server* en Visual Studio Code.
